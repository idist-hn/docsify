# Viettel Start Cloud

## Giới thiệu

Viettel Start Cloud là gói dịch vụ cloud server được thiết kế đặc biệt cho startup, doanh nghiệp nhỏ và các dự án khởi nghiệp. Với mức giá ưu đãi và cấu hình tối ưu, Start Cloud giúp bạn bắt đầu hành trình số hóa một cách dễ dàng và tiết kiệm.

## Đặc điểm nổi bật

### 💰 Giá cả phải chăng

- **Gói khởi nghiệp**: Chỉ từ 49,000 VNĐ/tháng
- **Miễn phí setup**: Không phí cài đặt ban đầu
- **Thanh toán linh hoạt**: Theo tháng hoặc theo năm
- **Ưu đãi dài hạn**: Giảm giá khi đăng ký 12 tháng

### 🚀 Dễ sử dụng

- **1-click deployment**: Triển khai ứng dụng chỉ với 1 click
- **Pre-configured templates**: Mẫu có sẵn cho WordPress, Laravel, Node.js
- **Auto-scaling**: Tự động mở rộng khi cần thiết
- **Backup tự động**: Sao lưu dữ liệu hàng ngày

### 🔧 Tính năng đầy đủ

- **SSD Storage**: Lưu trữ SSD tốc độ cao
- **Free SSL**: Chứng chỉ SSL miễn phí
- **CDN tích hợp**: Tăng tốc website toàn cầu
- **24/7 Support**: Hỗ trợ kỹ thuật 24/7
